# HFS Simulationen

Interaktive Labore und 3D-Modelle zur Elektrotechnik – frei nutzbar im Unterricht, zu Hause, auf iPad, Smartphone und PC.

Startseite: `index.html`

## Bedienung

- Jede Seite läuft direkt im Browser, ohne Anmeldung und ohne Installation.
- Über **Teilen** bzw. das QR-Symbol bekommst du für jede Seite einen QR-Code und einen Link zum Kopieren.
- Auf der Startseite steht unter **„Als App auf dem Gerät ablegen“**, wie du die Sammlung auf den Home-Bildschirm (iPad, iPhone, Android) oder als App auf PC/Mac legst. Danach funktioniert alles auch ohne Internet.
- Für Rechner ohne Internet gibt es ein **Offline-Paket** (`HFS-Simulationen-offline.zip`): entpacken und `index.html` öffnen.
- Bei Arbeitsaufträgen erscheint die Musterlösung erst, nachdem du deine eigene Antwort abgegeben hast. Antworten lassen sich als Textdatei speichern.

## Datenschutz

Die Seiten laden nichts von fremden Servern und senden keine Daten. Antworten und Spielstände bleiben im Browser auf dem jeweiligen Gerät.
